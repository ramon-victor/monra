# Changelog / Histórico de mudanças

All notable deployment changes are documented here. / Todas as mudanças relevantes do deploy são documentadas aqui.

## [0.1.0] - 2026-09-01

### English

- Initial single-host deployment for Studio, WA Service, PostgreSQL, Valkey, and optional Caddy.
- Secure secret generation, internal-only data services, signed webhooks, dependency-aware readiness, and one-shot migrations.
- CLI workflows for install, lifecycle, diagnostics, update/rollback, backup, and restore.
- Mirrored English and Brazilian Portuguese documentation.

### Português (Brasil)

- Deploy inicial de host único com Studio, WA Service, PostgreSQL, Valkey e Caddy opcional.
- Geração segura de segredos, bancos internos, webhooks assinados, prontidão com dependências e migrações one-shot.
- CLI para instalação, ciclo de vida, diagnóstico, atualização/rollback, backup e restauração.
- Documentação espelhada em inglês e português brasileiro.
