# Política de segurança

[English](./SECURITY.md)

Correções de segurança são fornecidas para a versão minor mais recente.

Relate vulnerabilidades pelo canal privado do GitHub. Não abra issue pública com `.env`, backups, tokens, URLs de banco, payloads, telefones ou dados de contas reais do WhatsApp.

Rotacione qualquer credencial possivelmente exposta antes de enviar um relato sanitizado.
