# Configuration

Run `./monra install`; it creates `.env` with independent 256-bit secrets and mode `600`. Do not commit this file. `versions.env` is committed because it contains image references, not credentials.

## Installation options

| Option | Purpose |
| --- | --- |
| `--bind IPv4` | Bind Studio to a trusted interface; default `127.0.0.1` |
| `--port PORT` | Host port for Studio; default `5522` |
| `--domain DOMAIN` | Enable the Caddy public profile and automatic HTTPS |
| `--email EMAIL` | ACME account email; required with `--domain` |
| `--no-pull` | Skip image pulls, useful only for local testing/recovery |
| `--no-start` | Generate and validate configuration without starting services |

## Core settings

| Variable | Meaning | Default generated by installer |
| --- | --- | --- |
| `MONRA_BIND_IP` | Interface that publishes Studio | `127.0.0.1` |
| `MONRA_PORT` | Published Studio port | `5522` |
| `MONRA_PUBLIC_URL` | Canonical URL used by authentication | Derived from mode |
| `MONRA_TRUSTED_ORIGINS` | Comma-separated browser origins | Derived from URL |
| `MONRA_ENABLE_HTTPS` | Activates the `public` Compose profile | `false` |
| `MONRA_DOMAIN` | Public DNS name | Empty |
| `MONRA_ACME_EMAIL` | Certificate account email | Empty |
| `MONRA_SAVE_MESSAGES` | Persist WA messages in PostgreSQL | `false` |
| `MONRA_WEBHOOK_FILES` | Include media data/URLs in callbacks | `true` |
| `MONRA_CONNECT_ON_STARTUP` | Reconnect saved instances after restart | `true` |
| `MONRA_WA_LOG_LEVEL` | WhatsApp library log level | `INFO` |
| `MONRA_IGNORE_GROUP_EVENTS` | Drop group events | `false` |
| `MONRA_IGNORE_STATUS_EVENTS` | Drop status/story events | `true` |

The password, authentication, API, and webhook variables are generated automatically. Never reuse one value for multiple fields and never paste them into issues or logs.

## Optional AI settings

Provider keys are intentionally blank. Add only the provider used by the selected `CHAT_AGENT_MODEL`:

- `AI_GATEWAY_API_KEY`
- `OPENCODE_API_KEY`
- `GROQ_API_KEY`
- `GEMINI_API_KEY`
- `OPENROUTER_API_KEY`
- `OPENAI_API_KEY` and `OPENAI_BASE_URL`
- `CHAT_AGENT_MODEL` and `CHAT_AGENT_MODEL_MAX_RETRIES`

After editing `.env`, run `./monra restart` and `./monra doctor`.

## Image versions

`versions.env` is the only image selection file. Infrastructure entries are digest-pinned. Application releases initially use semantic tags; after publishing a release, replace each with `tag@sha256:<manifest-digest>` to make it immutable across registries and time.

Never use `latest` in a production deployment.
